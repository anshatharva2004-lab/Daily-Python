# Daily Python

A collection of small Python lessons, exercises, and beginner projects. The repository follows a chapter-by-chapter path through core Python concepts, with practice problems alongside many lessons.

## Learning Path

| Folder | Topics |
| --- | --- |
| `chapter 1` | First Python programs and modules |
| `chapter 2` | Variables, data types, naming rules, and input |
| `chapter 3` | Strings, slicing, string methods, and escape sequences |
| `chapter 4` | Lists and tuples |
| `chapter 5` | Dictionaries and sets |
| `chapter 6` | Conditional statements |
| `chapter 7` | Loops, iteration, `break`, and `continue` |
| `chapter 8` | Functions, arguments, return values, and recursion |

Folders ending in `ps sheet` contain practice problems for the corresponding chapter. `PROJECT 1` contains a small Snake-Water-Gun game.

## Getting Started

Install Python 3, then clone the repository:

```powershell
git clone https://github.com/anshatharva2004-lab/Daily-Python.git
cd Daily-Python
```

Run a script from the repository root with Python. For example:

```powershell
python "chapter 1/first.py"
python "PROJECT 1/main.py"
```

The scripts are standalone exercises, so you can also open a file, follow along, and run it individually. Some programs prompt for input in the terminal.
